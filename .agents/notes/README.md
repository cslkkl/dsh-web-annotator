# notes/ — 决策记录

记录“当时为什么这么定”，以及被打败的替代方案。

## 命名

`YYYY-MM-DD-<主题>.md`，主题用英文 kebab-case。

## 状态行

每篇第 3 行写状态，取值 `生效` / `被取代` / `已否决` / `已归档`。
`被取代` 跟指针行，`已归档` / `已否决` 跟一句话理由。失效笔记就原地标注，不移动文件。
