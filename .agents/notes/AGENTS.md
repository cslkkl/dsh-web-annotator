# notes/ — 规则层

继承 [../../AGENTS.md](../../AGENTS.md)。

notes/ 特有约束：

- **第 3 行必须是状态行**，四值之一：`状态：生效` / `状态：被取代` / `状态：已否决` / `状态：已归档`。
- **`被取代` 必须跟指针行**；`已归档` / `已否决` 必须跟一句话理由。
- **每篇必须有“替代方案”**：不记录被打败的选项，下次会重诉同一个方案。
- **不建索引文件**，不逐篇列清单；这篇笔记管什么看文件名与标题。
- **不建 `archived/` 子目录**：失效笔记就地改状态行。
- **用现在时描述已实施的事实**；事实性变化（路径、默认值、机制名）就地更新，只有决策反转才写新笔记。
- 目录结构与命名见 [README.md](README.md)。
